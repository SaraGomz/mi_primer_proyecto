# Mi primer proyecto

## Objetivo
Configurar y validar un entorno de desarrollo profesional en Python, estableciendo una estructura limpia de directorios, control de versiones con Git y pruebas automatizadas mediante pytest.

## Herramientas utilizadas
- Python (versión: 3.14.4)
- Visual Studio Code (extensiones: Python, Pylance, Ruff)
- Git
- pytest

## Cómo ejecutarlo

    python src/main.py

## Cómo ejecutar las pruebas

    pytest

## Comandos básicos necesarios

git init
git status
git add .
git commit -m
python -m pytest
pytest
